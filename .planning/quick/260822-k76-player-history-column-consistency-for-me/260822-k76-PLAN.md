<objective>
Introduce admin-managed system columns (cross-team, immutable by coordinators) to enable consistent
cross-team history comparisons on the member player-profile page (/member/player-profile).

Purpose: Currently "Einsatz" in Team A and "Gespielt" in Team B are separate columns in history
because global columns are team-scoped. System columns with team_id=NULL solve this without
removing coordinator freedom to create their own team-scoped columns.

Output:
- DB migration making team_id nullable + adding is_system flag
- Admin CRUD page for system columns (/admin/columns linked from settings)
- Coordinator column list showing system columns as read-only (lock icon)
- Member history split into system-column section (main) + coordinator-column section (collapsible)
</objective>

Migration 028 steps (each in its own try/catch, idempotent):

**Step 1 — make team_id nullable on columns:**
```php
// check column constraint via information_schema, then ALTER
$pdo->exec("ALTER TABLE {$schema}.columns ALTER COLUMN team_id DROP NOT NULL");
```
Gate with an information_schema check: detect if column is currently NOT NULL, skip if already nullable.
Detection: query `information_schema.columns` for `is_nullable = 'NO'` on `columns.team_id`.

**Step 2 — add is_system column:**
```php
$pdo->exec("ALTER TABLE {$schema}.columns ADD COLUMN IF NOT EXISTS is_system BOOLEAN NOT NULL DEFAULT FALSE");
```

**Step 3 — promote all existing global columns to system columns (one-time):**
Decision from CONTEXT.md: ALL existing global columns (list_id IS NULL, is_system = FALSE) become
system columns because the productive system is managed by one person.
```php
$pdo->exec("UPDATE {$schema}.columns SET is_system = TRUE, team_id = NULL WHERE list_id IS NULL AND is_system = FALSE");
```
Gate: only run if the UPDATE would affect rows (check count first), or just run idempotently — re-running
sets is_system=TRUE team_id=NULL on already-updated rows, which is harmless.

**Step 4 — add index on is_system:**
```php
$pdo->exec("CREATE INDEX IF NOT EXISTS idx_columns_is_system ON {$schema}.columns(is_system)");
```

**Step 5 — update RLS policies (drop-and-recreate, idempotent):**

columns_visibility_select — extend to allow system columns (is_system=TRUE, list_id IS NULL) for any
user with a valid team context (authenticated users):
```sql
CREATE POLICY columns_visibility_select ON {schema}.columns FOR SELECT USING (
    current_setting('app.is_admin', true) = 'true'
    OR (is_system = TRUE AND list_id IS NULL
        AND NULLIF(current_setting('app.current_team_id', true), '') IS NOT NULL)
    OR (current_setting('app.current_role', true) = 'coordinator'
        AND team_id = NULLIF(current_setting('app.current_team_id', true), '')::integer)
    OR (list_id IS NULL
        AND team_id = NULLIF(current_setting('app.current_team_id', true), '')::integer)
    OR (list_id IS NOT NULL
        AND coach_only = FALSE
        AND team_id = NULLIF(current_setting('app.current_team_id', true), '')::integer
        AND EXISTS (SELECT 1 FROM {schema}.lists
                    WHERE lists.id = columns.list_id
                    AND lists.visibility IN ('public', 'protected')))
)
```

columns_delete — prevent coordinators from deleting system columns (is_system = FALSE guard):
```sql
CREATE POLICY columns_delete ON {schema}.columns FOR DELETE USING (
    current_setting('app.is_admin', true) = 'true'
    OR (current_setting('app.current_role', true) = 'coordinator'
        AND team_id = NULLIF(current_setting('app.current_team_id', true), '')::integer
        AND is_system = FALSE)
)
```

columns_insert — ensure coordinator inserts do not create system columns:
```sql
CREATE POLICY columns_insert ON {schema}.columns FOR INSERT WITH CHECK (
    current_setting('app.is_admin', true) = 'true'
    OR (current_setting('app.current_role', true) = 'coordinator'
        AND team_id = NULLIF(current_setting('app.current_team_id', true), '')::integer
        AND (is_system IS NULL OR is_system = FALSE))
)
```

- Add `CREATE INDEX IF NOT EXISTS idx_columns_is_system ON team_manager.columns(is_system)` after existing column indexes

Do NOT touch any other migration or table definition.

FROM cells ce
JOIN lists l ON l.id = ce.list_id
JOIN teams t ON t.id = l.team_id
