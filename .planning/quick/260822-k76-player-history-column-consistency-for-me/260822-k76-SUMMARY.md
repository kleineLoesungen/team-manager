## What Was Built

### Migration 028 (connection.php)
Five idempotent steps added at end of `maybe_migrate_db()`:
- Step 1: `ALTER TABLE columns ALTER COLUMN team_id DROP NOT NULL` (guarded by `information_schema` check)
- Step 2: `ADD COLUMN IF NOT EXISTS is_system BOOLEAN NOT NULL DEFAULT FALSE`
- Step 3: `UPDATE columns SET is_system = TRUE, team_id = NULL WHERE list_id IS NULL AND is_system = FALSE` (promotes all existing global columns)
- Step 4: `CREATE INDEX IF NOT EXISTS idx_columns_is_system`
- Step 5: Three RLS policies updated:
  - `columns_visibility_select`: system columns now visible to any authenticated user with team context
  - `columns_delete`: coordinators blocked from deleting system columns (`AND is_system = FALSE` guard)
  - `columns_insert`: coordinator inserts cannot create system columns

### Admin System Columns (/admin/columns)
- `columns_handler.php`: GET list + POST create (name, data_type boolean/number, sort_order)
- `column_action_handler.php`: GET confirm page + POST delete with cell-count guard
- Two templates with Bootstrap list-group / table UI following existing admin patterns
- Route added to `index.php` for both `/admin/columns` and `/admin/columns/{id}/delete`
- "Systemspalten" list item added to `/admin/settings` list-group

### Coordinator Column List (/coordinator/settings)
- `settings_handler.php`: new `$system_columns` query fetches `is_system=TRUE` columns; existing `$columns` query now filters `is_system=FALSE`
- `settings.php`: system columns rendered at top with `<span class="badge bg-light text-dark border"><i class="bi bi-lock-fill me-1"></i>System</span>` badge — no edit/delete actions
- Team-scoped columns follow unchanged with create form

### Member History (/member/player-profile)
- `player_profile_handler.php`: single `$cross_stats` query replaced with two queries:
  - `$system_stats`: `JOIN columns c ON ... AND c.is_system = TRUE` — ordered by sort_order, date DESC
  - `$coordinator_stats`: `JOIN columns c ON ... AND c.is_system = FALSE` — ordered by team, column name, date DESC
- `player_profile.php`: 
  - Section A: "Vergangene Einsätze" card using `$system_stats` with tab-switching JS (unchanged UX)
  - Section B: Bootstrap collapse (`data-bs-toggle="collapse"`) with "Koordinator-Spalten" button — only rendered when `!empty($coordinator_stats)`
