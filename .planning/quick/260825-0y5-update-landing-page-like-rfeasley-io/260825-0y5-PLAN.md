  <action>
Overwrite landing/index.html entirely. No Bootstrap, no Bootstrap Icons, no Google Fonts. All CSS lives in a single &lt;style&gt; block in &lt;head&gt;. No JavaScript.

**Design tokens (CSS custom properties):**
```css
--bg:      #fafaf9;   /* warm off-white */
--fg:      #111111;   /* near-black text */
--muted:   #6b6b6b;   /* secondary text, section numbers, captions */
--border:  #e0e0de;   /* thin borders */
--btn-bg:  #111111;   /* CTA button fill */
--btn-fg:  #fafaf9;   /* CTA button label */
```
No other color variables. No gradients. No box-shadows on sections.

**Typography:**
- Font: `font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif;`
- Body: `font-size: 1rem; line-height: 1.75; color: var(--fg);`
- h1: `font-size: clamp(2rem, 5vw, 3.25rem); font-weight: 700; letter-spacing: -0.025em; line-height: 1.1;`
- h2: `font-size: 1.35rem; font-weight: 700; letter-spacing: -0.01em; margin-bottom: 1.25rem;`
- Section number label (`.sec-num`): `display: block; font-size: 0.7rem; letter-spacing: 0.12em; text-transform: uppercase; color: var(--muted); margin-bottom: 0.75rem;`

**Layout:**
- `body { background: var(--bg); max-width: 100%; }`
- `.container { max-width: 660px; margin: 0 auto; padding: 0 1.5rem; }`
- Sections use `padding: 5rem 0;` (hero: `padding: 7rem 0 5rem;`)
- Section dividers: `border-top: 1px solid var(--border);`

**Structure — sections in order:**

1. **&lt;nav&gt;** — sticky, `background: var(--bg); border-bottom: 1px solid var(--border); padding: 1rem 0;`
   - Left: `&lt;a href="#"&gt;Team Manager&lt;/a&gt;` — `font-weight: 600; color: var(--fg); text-decoration: none;`
   - Right: `&lt;a href="https://github.com/kleineLoesungen/team-manager" target="_blank" rel="noopener"&gt;GitHub&lt;/a&gt;` — muted color, no underline until hover
   - Flex, space-between, align-items center

2. **Hero** — no background color change (inherits `var(--bg)`):

   ```html
       &lt;a href="https://github.com/kleineLoesungen/team-manager" target="_blank" rel="noopener" class="btn"&gt;Auf GitHub ansehen&lt;/a&gt;
     &lt;/div&gt;
   &lt;/section&gt;
   ```

   `.btn { display: inline-block; background: var(--btn-bg); color: var(--btn-fg); padding: 0.65rem 1.5rem; border-radius: 4px; text-decoration: none; font-weight: 600; font-size: 0.9rem; }`
