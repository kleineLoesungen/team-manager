## Copywriting Contract

All copy in German (du-speech per project convention).

### Primary CTA

| Action | Label | Context |
|--------|-------|---------|
| Post message | Posten | Message form submission button |
| Save ticker | Speichern | Ticker create/edit form submission |
| Save tag configuration | Speichern | Tag settings form submission |
| Close ticker | Schließen | Ticker status change (change to closed) |
| Delete ticker | Löschen | Destructive ticker removal action |
| Edit message | Bearbeiten | Message edit button (if applicable) |
| Delete message | Löschen | Message delete button (if applicable) |

### Empty States

| Page | Heading | Body | CTA |
|------|---------|------|-----|
| Coordinator ticker list (no tickers) | Noch keine Ticker erstellt | Du kannst einen neuen Ticker anlegen, um Events zu dokumentieren. | Button: + Neuer Ticker |
| Public ticker overview (no tickers) | Keine aktiven Ticker | Es sind derzeit keine Live-Ticker aktiv. | (no CTA on public page) |
| Message feed (no messages) | Keine Nachrichten noch | Der Ticker ist leer. Stelle eine Nachricht bereit, um den Ticker zu füllen. | (context-dependent) |
| Member ticker list (not freigegeben for any) | Keine Ticker verfügbar | Du hast noch keinen Zugriff auf einen Ticker. | (no CTA) |

### Error States

| Error | Problem | Solution Path |
|-------|---------|----------------|
| Message too long | "Nachricht darf maximal 280 Zeichen lang sein." | Character counter shows current length; user reduces text and resubmits |
| Empty message | "Nachricht darf nicht leer sein." | User adds text to textarea and resubmits |
| Invalid timestamp format | "Uhrzeit muss Format HH:MM haben." | User corrects time input (browser time picker enforces format) |
| Member not authorized to post | "Du darfst in diesem Ticker nicht posten." | (403 Forbidden) Only coordinators and freigegeben members can post; direct POST attempt from non-authorized member fails silently |
| Ticker not found | 404 Not Found | User navigates back to coordinator ticker list or public overview |
| Tag configuration save error | "Fehler beim Speichern der Tag-Konfiguration. Bitte versuche es erneut." | User retries; server-side error logged |

### Destructive Actions

**Ticker deletion (two-step confirm):**

Step 1 (confirmation prompt):
- Heading: "Ticker löschen"
- Copy: "Dieser Ticker und alle Nachrichten werden dauerhaft gelöscht. Diese Aktion kann nicht rückgängig gemacht werden."
- Button: "Jetzt löschen" (danger color) | "Abbrechen" (secondary)

Step 2 (success feedback):
- Alert banner (success color): "Ticker gelöscht."
- Redirect to: `/coordinator/ticker` (ticker list)

**Message deletion (within ticker detail):**
- Inline confirmation: "Nachricht löschen? Diese Aktion kann nicht rückgängig gemacht werden."
- Button: "Löschen" (danger color)
- Success: Message disappears, no page reload
- Fallback (without JS): PRG pattern — POST to `/coordinator/ticker/{id}/message/{msg_id}/delete` → redirect back to ticker detail with `?success=message_deleted`

## Component Patterns

### Message Card (Ticker Feed)

**Structure:**
```
┌────────────────────────────────┐
│ 14:35 [Tor] (badge)            │  ← Timestamp (strong) + optional tag badge
│                                │
│ Schönes Tor von Meier ins       │  ← Message text (paragraph)
│ linke obere Ecke               │
│                                │
│ [Bearbeiten] [Löschen]         │  ← Edit/delete buttons (coordinator only)
└────────────────────────────────┘
```

**Styles:**
- Container: `.card` with `.mb-2` (8px margin-bottom)
- Body: `.card-body` with default padding (1rem)
- Timestamp: `<strong>` with text-dark
- Tag badge: `<span class="badge bg-{color}">` (inline with timestamp, margin-left 4px)
- Message: `<p class="mb-0">` (no margin to prevent vertical gaps)
- Edit/delete: Buttons placed in card footer or as separate row with text-end alignment

**Responsive:** Card wraps on mobile; full width on all screens via Bootstrap grid.

### Message Post Form (Authenticated Areas)

**Layout:**
- Field 1: Message textarea (full width)
- Field 2 & 3: Timestamp (left, 50%) + Tag dropdown (right, 50%) on desktop; stacked on mobile
- Field 4: Submit button (full width on mobile, auto on desktop)

**Styles:**
- Textarea: `.form-control` with `maxlength="280"`
- Timestamp input: `type="time"` with `.form-control`
- Tag select: `.form-select`
- Submit: `.btn .btn-primary`

**Validation (Client + Server):**
- HTML5 `maxlength="280"` + `required` on textarea
- HTML5 `type="time"` enforces HH:MM format on timestamp input
- Server-side: `mb_strlen($message) <= 280` + regex `/^\d{2}:\d{2}$/` for timestamp

### Ticker List (Coordinator View)

**Structure:**
- Header: "Ticker" with optional search/filter (not Phase 07 scope)
- List: Table or card grid (responsive)
  - Card per ticker showing: name, status badge, created_at, actions (view, edit, close, delete)
  - Active tickers prominent (brand color header or top placement)
  - Closed tickers below or with muted styling

**Status badges:**
- Active: `<span class="badge bg-success">Aktiv</span>`
- Closed: `<span class="badge bg-secondary">Geschlossen</span>`

**Actions:**
- View ticker (link to detail): "Ansehen"
- Edit ticker (link to form): "Bearbeiten"
- Close ticker (POST button): "Schließen"
- Delete ticker (link to confirmation page): "Löschen" (danger color)

### Ticker Settings Page (Tab or Section)

**Rename from `/coordinator/columns` to `/coordinator/settings`**

**Structure:**
- Heading: "Einstellungen"
- Section 1: "Spalten" (existing columns management, no changes to Phase 3 content)
- Section 2: "Ticker-Tags" (new, Phase 07 addition)

**Ticker-Tags section:**
- Intro text: "Team-weit verfügbare Tags für Nachrichten."
- Table or card list showing: tag label, color badge, actions (edit, delete)
- Button: "+ Neues Tag" (creates new tag form)
- Tag form fields: label, color dropdown, sort_order (optional)

### Public Ticker Overview (`/ticker`)

**Structure:**
- Page title: "Öffentliche Ticker"
- Active tickers section (top):
  - Heading: "Aktive Ticker"
  - Card grid: Each ticker shows name, description, message count, link to view
- Closed tickers section (bottom, muted):
  - Heading: "Abgeschlossene Ticker"
  - Card grid (similar, but text-muted styling)

**Card styling:**
- Active: Default Bootstrap card (white, shadows)
- Closed: Text-muted class applied to text; background-light

### Auto-Reload Script

**Placement:** In public ticker detail template (`src/templates/public/ticker_detail.php`)

**Condition:** Only rendered if `$ticker['status'] === 'active'`

**Implementation:**
```html
<?php if ($ticker['status'] === 'active'): ?>
    <script>
        setTimeout(() => {
            location.reload();
        }, 5000);
    </script>
<?php endif; ?>
```

**No countdown timer, no animated indicator** (per D-02 decision: silent hint only).

## Design Decisions Summary

**What was NOT changed from Phase 1–6:**
- Spacing scale (Bootstrap 8-point)
- Typography (1rem body, h4 headings)
- Color system (brand color + Bootstrap palette)
- Icon library (Bootstrap Icons)
- Layout pattern (sidebar + mobile tabs)

**What is NEW in Phase 07:**
- Message card component (ticker feed display)
- Character counter form (message posting)
- Status badges (active/closed)
- Tag color badges (message categorization)
- Auto-reload script (vanilla JS, conditional)
- Public ticker overview page
- Settings page rename (Spalten → Einstellungen)
- Member freigabe checkboxes (in ticker edit form)

**Rationale:**
All Phase 07 UI decisions follow established project patterns to maintain consistency and reduce cognitive load. No new frameworks, libraries, or design systems introduced. Bootstrap components and Vanilla JavaScript sufficient for all interactions.
