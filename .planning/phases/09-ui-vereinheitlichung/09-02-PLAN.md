  <action>
  Apply the following changes to src/templates/coordinator/lists.php. The file is a template
  body (the callable passed to render_coach_page). It does NOT call render_coach_page itself —
  that is done by the handler. You only edit the template body contents.

  **Violation checklist — apply every point:**

  1. INLINE STYLES: Remove every `style="..."` attribute found in the file.
     Exception: `onerror="this.style.display='none'"` on `<img>` tags is ALLOWED — do not remove it.

  2. EMPTY STATE: Find any `<div class="text-center py-5">` (or similar patterns with `py-5`).
     Replace with `render_empty()` calls. For the lists overview empty state, use:
     ```php
     <?php render_empty('collection', 'Noch keine Einträge', 'Lege die erste Liste oder Datei an.'); ?>
     ```

  3. SPACING VIOLATIONS: Replace any `mb-5` → `mb-4`. Remove any `py-5` that was not already
     replaced by render_empty(). Remove any `*-0` or `*-1` spacing utilities.

  4. VISIBILITY BADGES: Replace inline badge HTML with render_badge() calls.
     BEFORE:
       `<span class="badge bg-success">Öffentlich</span>`
       `<span class="badge bg-warning text-dark">Geschützt</span>`
       `<span class="badge bg-secondary">Privat</span>`
     AFTER:
       `<?php render_badge('ok', 'Öffentlich'); ?>`
       `<?php render_badge('warn', 'Geschützt'); ?>`
       `<?php render_badge('dim', 'Privat'); ?>`
     The $badge_class and $badge_label helper closures at the top of the file can be removed
     once all their usages are replaced with render_badge().

  5. COLLECTION GROUPS: Where the template renders a section heading (e.g., a `<p class="tm-group-label">` or similar date/group headers), wrap it in render_collection_group(). Pattern:
     ```php
     <?php render_collection_group($date_label, function() use ($group_items) { ?>
         <!-- list-group-item elements for this group -->
     <?php }); ?>
     ```
     If the template already uses `.tm-group-label` directly, wrap it in render_collection_group instead.

  6. FONT-SIZE VIOLATIONS: Remove `style="font-size:2rem;"` from any icon elements.
     The `.tm-empty .bi` CSS already handles icon sizing.

  7. FORM-CONTROL-SM: Remove `-sm` suffix from any `form-control-sm`, `form-select-sm`,
     `input-group-sm` on form inputs (not table action columns).

  8. SUCCESS FLASH: Add ?success=1 support at the top of the template body (before other content):
     ```php
     <?php if ($_GET['success'] ?? null): render_flash('success', 'Gespeichert.'); endif; ?>
     ```
     Also add the URL-cleanup JS snippet (copy from existing lines 363–374 in the file, or use):
     ```javascript
     <script>
     (function() {
         var url = (location.pathname + location.search).replace(/[?&]success=1/, '').replace(/\?$/, '');
         if (url !== location.pathname + location.search) history.replaceState(null, '', url);
     })();
     </script>
     ```
     Place this script in render_layout_foot's JS block OR at the bottom of the template body.

  9. SHADOW-SM: Remove `shadow-sm` class from any card elements.

  10. NO NEW FUNCTIONS: Do not add require_once for partials. They are already available
      because layout.php includes components/partials.php before the template body executes.

  The template still uses render_coach_page() (called by the handler). Do NOT change that call.
  Do NOT emit `<html>`, `<head>`, or `<body>` tags in the template.
  </action>
